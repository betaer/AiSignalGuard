# 新版检测逻辑修复与验证记录

范围：正式根页与 `/v2/`。`/v1/`、旧 IPCX 页面及其运行逻辑保持不变。

## 已修复的问题

| 问题 | 处理 |
|---|---|
| 隐私模式漏掉说明文字、路由范围和音频摘要 | 对内嵌 IPv4 / IPv6 统一遮罩，处理相邻标点；音频摘要显示与单项复制同步脱敏 |
| 总览忽略 DNS 异常和明确风险标签 | 总览纳入 DNS 地区差异、失败、代理 / 机房标签和来源冲突 |
| STUN 收到第一个候选便关闭连接 | 等待收集结束，保留全部去重候选；超时保留部分结果并标明不完整 |
| 请求超时只覆盖响应头 | 统一请求工具将响应正文读取、取消与超时放在同一生命周期 |
| 等价 IPv6 被认成不同地址 | 比较前统一 IPv6 表示形式 |
| HTTP 失败后仍出现满覆盖率、高分 | 总览使用固定模块权重；核心证据缺失时不评分 |
| 所有 America 时区被归到美国 | 使用带版本号的 IANA 时区 / 国家表，保留共享地区和历史别名 |
| 组织名称格式差异拆散投票 | 复用组织规范化规则，并要求足够票数、占比和领先幅度 |
| 动态说明提示未更新 | 修正提示元素定位，更新本轮说明与建议 |
| 页面宣传 AI 服务路径但缺少对应检测 | 增加 ChatGPT、Claude、Gemini 三项探针，分别保留可读路径、资源、受限和未知状态 |

另修正首次确认前本地明细错误显示“已读取”的问题，并为异常中止增加重测控件恢复保护。

根页与 `/v2/` 共用 `v2/core.js`、`v2/evidence.js`、`v2/app.js` 和时区数据，避免两套内联实现继续分叉。中英文 README 同步说明实际能力与隐私开关行为。

## 验证

- 构建、JavaScript 语法及生成文件一致性检查通过。
- Node.js 测试：124 / 124 通过，无跳过。
- 新版专项单元 / 集成测试：14 / 14 通过，包含真实 HTTP 慢响应体和取消测试。
- 新核心模块覆盖率：行 100%，分支 90.35%，函数 98.25%；三项均设置 80% 门槛。
- 新版真实浏览器回归覆盖首次确认、双栈、后到 IPv6、DNS 异常、无 HTTP、代理标签、隐私显示与剪贴板、不透明 AI 响应、重测和手机布局。
- 历史 v1 / Demo 兼容回归：70 个场景、404 / 404 条断言通过；IPCX 与 Remix 页面回归通过。
- 浏览器执行字节覆盖率：核心模块 88.04%，证据模块 86.14%，页面控制器 86.24%；每个模块设置 80% 门槛。此指标与行 / 分支覆盖率不同，不混用。
- 变更差异、调试语句、敏感凭据模式和不可信内容写入方式已检查；这不替代独立安全审计。
- 项目没有独立 TypeScript 类型检查或 ESLint 配置；本次使用 JavaScript 语法检查与自动化回归，不宣称通过未配置的检查。

浏览器回归使用受控第三方响应，以验证判断逻辑，不代表所有公开服务在每个网络都可用。AI 的 `no-cors` 不透明响应无法读取状态或正文，始终保持待核对；资源可达不代表登录、对话或账号功能可用。
