# 右下角 X 浮动入口设计

## 目标

在当前新版根入口与 `/v2/` 的右下角快捷工具栏中，紧接 GitHub 入口增加 Betaer 的 X 主页入口，同时维持现有桌面纵向、移动端横向的统一工具栏结构。

## 已确认交互

- 入口地址固定为 `https://x.com/Betaer`，点击后在新窗口打开。
- 桌面端顺序为 GitHub 在上、X 在下；X 按钮保持与其他浮动按钮相同的 `48 × 48px` 圆形尺寸和对齐方式。
- 桌面端显示 X 品牌图标，并持续展示文字标签“X”；标签位于按钮左侧，不改变按钮本身的宽度。
- 移动端继续使用底部横向工具栏，只显示 X 图标，不显示文字标签。
- X 图标使用页面内联 SVG，不增加第三方图片请求；链接包含 `noopener noreferrer`，避免新窗口访问原页面上下文。
- 只修改 `index.html` 与 `v2/index.html`，保留 `/v1/` 在线归档不变。

## 响应式与可访问性

- X 入口复用 `.floating-tool-button` 的悬停、焦点、阴影和触控状态。
- 增加明确的 `aria-label` 与 `title`，说明将打开 Betaer 的 X 主页。
- `680px` 以下沿用现有隐藏浮动标签规则；`360px` 以下适当压缩所有按钮宽度，确保新增第七项后在 `320px` 视口仍不横向溢出。
- 打印样式继续隐藏整个浮动工具栏。

## 验收标准

- 根入口和 `/v2/` 均出现唯一的 X 入口，且位于 GitHub 入口之后。
- 桌面端 X 按钮尺寸与其他按钮一致，图标与“X”标签可见。
- 移动端只显示 X 图标，`320px` 视口工具栏不溢出。
- `/v1/` 不出现新增入口。
- 版本结构测试、浏览器测试与全量检查全部通过。
