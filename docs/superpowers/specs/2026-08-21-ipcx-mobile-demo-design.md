# IP.cx 移动结果卡 Demo 设计说明

## 目标

新增一个完全独立的 `index-ipcx.html` 本地演示页，验证 AiSignalGuard 是否可以借鉴 IP.cx 的简洁检测结果结构，并重点验证手机端截图与结果分享体验。

## 设计方向

- 视觉：冷灰背景、单一绿色主色、白色信息卡、轻量边框和低阴影；保持 AiSignalGuard 的绿色状态语言，不复制 IP.cx 品牌。
- 结构：先给“结论 + 风险标签 + 关键数据”，再通过模块切换查看 WebRTC 和浏览器指纹摘要。
- 分享：结果卡本身可直接截图，同时提供分享预览、复制摘要和 PNG 下载。
- 隐私：默认隐藏 IP 最后一段；切换隐私状态时同步更新结果卡、详情和分享图。
- 数据：使用脱敏的本地模拟数据，不发起检测请求，不修改现有应用状态。

## 页面组成

1. 顶部品牌条与模块导航：总览、WebRTC、浏览器指纹。
2. 手机优先结果卡：综合状态、参考分、风险标签、出口位置、检测时间。
3. 关键状态网格：出口 IP、位置、DNS、WebRTC、浏览器、IP 互证。
4. 模块详情区：
   - WebRTC：HTTP 出口、WebRTC 公网地址、内网地址、STUN 节点结果。
   - 浏览器指纹：FingerprintJS v3+、FingerprintJS2、JA3 / JA4 三种摘要切换。
5. 固定操作栏：生成分享图、复制摘要、隐私切换、重新检测。
6. 分享预览弹窗：预览可发布结果卡并下载 PNG。

## 交互与边界

- 模块导航只改变当前详情视图，不刷新页面。
- 重新检测展示短暂的“检测中”状态后恢复完成态，证明 loading / done 视觉闭环。
- 复制失败时使用页面内提示，不依赖第三方库。
- 分享图使用浏览器 Canvas 本地生成，不上传数据。
- 所有按钮有键盘焦点、可读标签和 `aria-live` 状态提示。

## 验收标准

- 390px 宽度下无需横向滚动，结果卡和固定操作栏都完整可用。
- 默认状态不暴露完整 IP；隐私切换可明确显示当前状态。
- WebRTC 与指纹视图有真实的模块差异，不只是换标题。
- PNG 分享动作可生成下载文件；复制动作有可见成功提示。
- Demo 不引入第三方运行时依赖，不影响现有首页构建和测试。
