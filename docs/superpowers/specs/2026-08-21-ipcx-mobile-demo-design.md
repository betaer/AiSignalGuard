# IP.cx 移动结果卡 Demo 设计说明

## 目标

新增一个完全独立的 `index-ipcx.html` 本地演示页，验证 AiSignalGuard 是否可以借鉴 IP.cx 的简洁检测结果结构，并重点验证手机端截图与结果分享体验。

## 设计方向

- 视觉：冷灰背景、单一绿色主色、白色信息卡、轻量边框和低阴影；保持 AiSignalGuard 的绿色状态语言，不复制 IP.cx 品牌。
- 结构：先给“结论 + 风险标签 + 关键数据”，再通过模块切换查看 WebRTC 和浏览器指纹摘要。
- 分享：结果卡本身可直接截图，同时提供分享预览、复制摘要和 PNG 下载。
- 隐私：默认隐藏 IP 最后一段；切换隐私状态时同步更新结果卡、详情和分享图。
- 数据：使用脱敏的本地模拟数据，不发起检测请求，不修改现有应用状态。

## 页面组成

1. 顶部品牌条与模块导航：总览、WebRTC、浏览器指纹。
2. 手机优先结果卡：综合状态、参考分、风险标签、出口位置、检测时间。
3. 关键状态网格：出口 IP、位置、DNS、WebRTC、浏览器、IP 互证。
4. 模块详情区：
   - WebRTC：HTTP 出口、WebRTC 公网地址、内网地址、STUN 节点结果。
   - 浏览器指纹：FingerprintJS v3+、FingerprintJS2、JA3 / JA4 三种摘要切换。
5. 固定操作栏：生成分享图、复制摘要、隐私切换、重新检测。
6. 分享预览弹窗：预览可发布结果卡并下载 PNG。

## 关键状态折叠信息架构

关键状态不再使用六张只能展开一句话的摘要卡，而是改为默认收起的一级行。一级行同时显示大标题、简洁测评结果、状态色和信号数量；点击后在原位展开全部详情内容。

- 出口 IP：使用「位置一致性、网络类型」两个普通文字分组标题，详情包含公网地址、位置、ASN、组织 / ISP、服务商类型、IP 质量和一致性核对。
- 身份信号：使用「时区、语言」两个普通文字分组标题，详情包含浏览器语言、系统时区、Emoji 渲染和中文字体。
- 网络泄漏：使用「DNS、WebRTC」两个普通文字分组标题，详情包含 HTTP 出口、WebRTC 公网 / 内网候选、STUN 结果、DNS 解析器数量和地区一致性。
- 多源互证：使用「地理交叉、网络标签」两个普通文字分组标题，详情包含可用来源数、主流地区、冲突数、来源名称和最终判断。

所有一级行默认收起。一级行展开后，两个文字分组及其全部详情行同时出现，不提供 Tab、按钮或隐藏面板切换。分组标题只使用普通文字、细分隔线和状态摘要，不使用 H1 / H2、大面积背景框或选中态。详情行继续支持展开检测结果、证据说明与建议；手机与桌面均按同一纵向顺序展示。

### 一级摘要与数字口径

一级行右侧统一为两层信息，不加入 Emoji 或额外状态图标：第一行只显示定性结论，第二行只显示当前一级组内可展开的详情数量。来源覆盖率、异常数量和票数不与详情数量并列，避免同一区域同时出现多个不同含义的数字。

- 出口 IP：`可信 · 部分匹配`，下方为 `6 项详情`。
- 身份信号：`存在待核对项`，下方为 `4 项详情`；具体待核对数量由内部详情呈现。
- 网络泄漏：`未发现明显泄漏`，下方为 `4 项详情`。
- 多源互证：`多源结果一致`，下方为 `5 项详情`。

`6 / 8 来源可用`属于数据来源覆盖率，只在「多源互证 → 网络标签」内部展示，并保留分母以说明完整口径。两个普通文字分组之间使用低对比度的 1px 虚线分隔，不能形成卡片标题或强分区边框。

## 交互与边界

- 模块导航只改变当前详情视图，不刷新页面。
- 重新检测展示短暂的“检测中”状态后恢复完成态，证明 loading / done 视觉闭环。
- 复制失败时使用页面内提示，不依赖第三方库。
- 分享图使用浏览器 Canvas 本地生成，不上传数据。
- 所有按钮有键盘焦点、可读标签和 `aria-live` 状态提示。

## 验收标准

- 390px 宽度下无需横向滚动，结果卡和固定操作栏都完整可用。
- 默认状态不暴露完整 IP；隐私切换可明确显示当前状态。
- WebRTC 与指纹视图有真实的模块差异，不只是换标题。
- 关键状态一级行默认收起，展开后两个普通文字分组及其所有详情行同时可见；页面不存在二级 Tab 或被隐藏的详情分组。
- 四个一级摘要均使用“定性结论 + N 项详情”的统一结构，不使用 Emoji，不在一级摘要显示来源覆盖率或异常数量。
- 多源覆盖率仅在内部显示为 `6 / 8 来源可用`，普通文字分组之间使用弱化虚线。
- 每个详情行都包含具体检测值，不以单句证据代替列表。
- PNG 分享动作可生成下载文件；复制动作有可见成功提示。
- Demo 不引入第三方运行时依赖，不影响现有首页构建和测试。
