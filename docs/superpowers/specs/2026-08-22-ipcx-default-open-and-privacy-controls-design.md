# index-ipcx 默认展开与隐私控件优化设计

日期：2026-08-22

## 目标

仅修改 `index-ipcx.html`，提升结果浏览效率、分数环视觉精度和隐私状态表达的一致性。

## 方案选择

采用“复用正式页视觉语言、保持 Demo 单一职责”的方案：借用 `index.html` 右下角圆形悬浮按钮的尺寸、描边、阴影和眼睛图标，但不复制重新检测、分享、GitHub、回到顶部等整组工具。相比继续保留顶部文字按钮，这种方案不会挤占品牌栏；相比复制整条工具栏，也不会与 Demo 已有底部操作栏重复。

## 交互设计

1. `出口 IP`、`身份信号`、`网络泄漏`、`多源互证` 四个一级 `<details>` 默认带 `open`，页面首次打开即可看到各分区及其二级行。
2. 19 个二级 `.signal-row` 不添加 `open`，仍保持默认收起。
3. 桌面端隐私控制移动到页面右下角，使用圆形眼睛 / 隐藏眼睛图标和悬浮标签：
   - 隐私开启时显示“显示原值”，图标为带斜线眼睛，表示点击后可显示。
   - 显示原值时显示“隐藏原值”，图标为普通眼睛，表示点击后可重新隐藏。
4. 手机端继续使用现有底部操作栏中的隐私按钮；桌面悬浮按钮在手机断点隐藏，避免重复入口。

## 隐私规则

1. IPv4 从只隐藏最后一段升级为隐藏后两段：`38.92.27.182` → `38.92.x.x`，DNS 示例地址同样处理。
2. 所有已经标记 `data-sensitive="ip"` 的字段继续复用同一遮罩函数，打开原值后分别恢复自己的原始值。
3. FingerprintJS v3/v2 隐私态继续保留前 8 位作为可辨认摘要。
4. JA3 / JA4 隐私态直接显示“已隐藏”，不再出现 `_••••`；显示原值时展示完整本地模拟 JA4 值。

## 分数环布局

把分值与标签包进独立的纵向居中容器，使用绝对几何中心而非依赖匿名 `<div>` 和文字自然基线。数字取消会造成左偏观感的负字距，标签使用明确的块级居中与稳定行高。桌面和手机尺寸都保持同一居中规则。

## 响应式与可访问性

- 悬浮按钮只在 `min-width: 681px` 显示，固定在右下安全边距内。
- 保留可见焦点、`aria-pressed`、动态 `aria-label` 和 `title`。
- 一级默认展开不改变键盘操作，用户仍可手动收起。
- 320px、390px、1280px 均要求无横向溢出；手机底部栏不得被桌面悬浮按钮遮挡。

## 验收标准

- 首次加载时 4 个一级分组全部展开，19 个二级行全部收起。
- 分数数字和“网络参考分”在圆环内水平、垂直视觉居中。
- 隐私开启时出口 IP 显示 `38.92.x.x`，DNS 示例地址显示 `198.51.x.x`。
- JA3 / JA4 隐私开启时显示“已隐藏”，关闭隐私后显示完整模拟值。
- 桌面顶部不再出现隐私文字按钮；右下角出现圆形隐私按钮。
- 手机仅保留底部栏隐私入口。
- 页面无脚本错误，现有 18 个复合证据区及测试全部通过。
