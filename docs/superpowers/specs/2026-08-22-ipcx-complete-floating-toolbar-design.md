# IPCX 完整浮动工具栏设计

## 目标

在 `index-ipcx.html` 中默认展示原始检测值，并把正式页已有的 AI 诊断、GitHub Star 和回到顶部能力完整迁入当前浮动工具栏。

## 已确认交互

- 页面初次加载时 `privacy` 为关闭状态，IPv4、浏览器指纹和 JA3 / JA4 均展示原值。
- 隐私按钮初始动作名为“隐藏原值”；点击后统一遮罩 IP 后两段，普通指纹保留前八位，JA3 / JA4 显示“已隐藏”。
- 使用一套响应式浮动工具栏，顺序为：重新检测、复制给 AI 诊断、复制摘要、隐私显示、GitHub、回到顶部。
- 桌面端保持右下角纵向圆形按钮；手机端改为底部横向圆形按钮，不再维护另一套重复按钮与事件。
- AI 诊断按钮复用 `assets/merged_ai_logo.svg`，复制一段包含评分、关键状态、网络、泄漏、来源和指纹信息的结构化文本，供 ChatGPT / Claude 分析。
- GitHub 按钮链接 `https://github.com/betaer/AiSignalGuard`，从 GitHub 公共 API 读取 Star 数，缓存 30 分钟；请求失败时显示 `Star`，不影响其他功能。
- 回到顶部使用 `#main` 锚点和平滑滚动。

## 状态与反馈

- 重新检测保留旋转状态、禁用状态、Toast 和读屏播报。
- 两个复制按钮分别维护独立的成功状态和图标，避免互相覆盖。
- GitHub 请求只更新 Star 徽标和无障碍名称，不阻塞页面初始化。
- 所有按钮保留明确的 `aria-label`、键盘焦点和移动端可触达尺寸。

## 验收

- 初始页面出现完整原始 IP 与完整指纹，隐私按钮显示“隐藏原值”。
- 桌面和 390px、320px 手机视口都能看到六项工具且无横向溢出。
- AI 诊断、摘要复制、隐私切换、重新检测、GitHub 链接与回到顶部均可独立使用。
- GitHub API 成功、缓存和失败回退都不会产生未处理异常。
- 四个一级分组仍默认展开，二级详情仍默认收起，现有测试全部通过。
