# 新版第二轮逻辑修复与验证

范围为正式根页与 `/v2/`，共用同一套检测逻辑。`/v1/`、旧 IPCX 页面、旧版运行脚本和共享历史弹窗策略未修改。

## 修复内容

| 问题 | 修复与验证重点 |
|---|---|
| 公网 host IPv6 被忽略 | 同时保留公网 host 与服务器反射候选；前者参与同族 HTTP 核对，但不计作 STUN 服务器响应 |
| 路由仅按响应数量计入总览 | 校验查询 IP、前缀、RDAP 范围与查询 ASN；真实目标的路由 ASN 分歧、多起源和查询对象不匹配进入总览及复制报告 |
| 失败请求误计为明确字段冲突 | 只计有效、可比较字段的实际差异；请求失败和自回显路径不同单独保留 |
| 地理票数不足被标成地区分歧 | 未形成可靠共识时使用中性“共识不足”，不把与空基准比较的结果标红 |
| DNS 缺少地区却显示绿色一致 | 总览、分组、子栏目、明细与地区行共用双栈地区判断；缺少地区或出口共识时保留未知 |
| 音频重测与全局重测竞态 | 全局检测复用并等待活跃音频任务，避免音频仍运行时宣布完成；全局检测中不叠加音频任务 |
| 未确认首次弹窗就保存 12 小时许可 | 只在点击 Star 或“先测试”后保存新版确认记录；关闭、刷新不授权，根页与 v2 共享确认，旧展示记录不迁移为许可 |

补充边界修复：未确认前禁用单独音频按钮；校验非法 CIDR 长度；ICE SDP 只读取候选地址字段，不把 `raddr` 误当候选；ASN 补充资料不替代目标 IP 的路由起源；异常中止不再播报“完成”。

## 新版验证

- `npm run check:full` 全部通过：Node 测试 131 / 131，无跳过；构建、语法和生成文件一致性检查通过。
- 新版单元与集成回归 21 / 21 通过，包含真实 HTTP 慢响应体、取消、非法地址、存储不可用和多起源边界。
- 核心模块覆盖率：行 100%、分支 90.29%、函数 98.68%，均高于 80% 门槛。
- 根页和 `/v2/` 的真实 Chromium 回归通过：正常双栈、无 HTTP、后到 IPv6 分歧、公网 host、路由错误、弱地理共识、DNS 地区缺失、请求失败、AI 不透明响应、隐私显示与复制、音频与全局重测竞态、首次确认和跨入口 12 小时抑制。
- 浏览器执行字节覆盖率：核心 88.53%、证据模块 88.51%、页面控制器 86.74%。这是执行字节指标，不等同于行或分支覆盖率。
- 可见浏览器使用未替换的真实接口完成检测：17 / 20 个 STUN 节点返回候选；本轮未观察到公网 host；没有未捕获的页面异常或停留在 pending / loading 的来源。
- 真实音频重测三轮完成，新增网络请求为 0。桌面及 390px 手机布局检查通过，已检查脱敏截图。
- 真实外部接口中的 HTTP 429、CORS、连接失败等保留原状态；这些是本轮环境和来源限制，不当作安全、泄漏或平台账号状态的确定结论。
- 历史 v1 / Demo 回归 70 个场景、404 / 404 条断言通过；IPCX、Remix v1.2、v1.3 的浏览器回归与 8 / 8 项语义回归通过。
- 发布前再次逐字节比较 `/v1/`、旧版 HTML 与共享历史运行脚本，确认与修复前一致；根页与 `/v2/` 的入口合同测试再次通过。

## 检查范围说明

JavaScript 语法、生成文件一致性、构建、版本入口合同、差异和敏感凭据模式均纳入验证。项目没有独立 TypeScript 类型检查或 ESLint 配置，不宣称通过未配置的检查。自动化覆盖率和一次真实网络检查不能证明所有浏览器、网络或公开接口均无问题。

本次采用测试驱动修复：先记录可复现的失败断言，再修改实现并复测。截图和运行日志放在本地忽略的输出目录，不随发布上传用户的实时网络证据。
